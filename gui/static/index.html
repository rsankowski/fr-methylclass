Methylation-based Tumour Classification

fr-methylclass · crossNN · MethyLYZR · Sturgeon V2 · Lamprey · rapidCNS2

⚠ EXPERIMENTAL — RESEARCH USE ONLY. These classifiers and all results they produce are purely experimental. They are not validated for diagnostic use and must not be used as the basis for any clinical or forensic decision. Interpret every result with appropriate caution.

1  Input BAM files

Add individual BAM files, a folder of BAMs, a folder containing sub-folders of BAMs (searched recursively), or a sample,bam CSV samplesheet.

    Sample grouping:

    2  References & models

    crossNN aligns to hg19; MethyLYZR, Lamprey, copy-number and rapidCNS2 to hg38; Sturgeon V2 to T2T-CHM13v2.0. The models folder is the one filled by scripts/download_assets.sh. These paths are saved on this computer and reused next time.

    3  Classifiers

    Tick the tools to run. The PDF report summarises everything else that ran for a sample. rapidCNS2 and Metagenomics are full nested pipelines (heavy, off by default); Lamprey covers haematological classes only.

    4  Output & options

    Advanced parameters for this run

    One name = value per line; any parameter of nextflow.config, e.g. lamprey_model = /models/lamprey, crossnn_top_n = 5, continue_on_error = false.
